Web client

Server-side is the sturdier option and behaves identically to your phone and TV apps. The browser option avoids re-encoding and responds instantly, but it depends on the web client's internals and needs script injection to be working.
Edits the web client's index.html so the volume slider is available in the browser. This is undone cleanly when you untick it. If the file is not writable by the Jellyfin process, the rest of the plugin still works.
