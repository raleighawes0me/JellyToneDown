Theme volume

Turns down theme music and theme videos only. Nothing else in your library is affected, and the files on disk are never modified.

Applies to everyone who has not set their own level below.

Web client

Server-side is the sturdier option and behaves identically to your phone and TV apps. The browser option avoids re-encoding and responds instantly, but it depends on the web client's internals and needs script injection to be working.
Puts a volume slider in the web client while a theme is playing. If this cannot be made to work, the rest of the plugin is unaffected.
The first needs no write access to the web client and cannot be undone by a Jellyfin upgrade, which is why it is the default. The second is the older approach: it edits index.html when the server starts, so it only works where that file is writable by the Jellyfin process, and it has to be re-applied after every web client upgrade. Switching back to the first removes anything the second wrote.
